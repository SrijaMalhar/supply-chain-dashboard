# Roadmap

## Done

- Parts CRUD with full audit log
- Pipeline stage tracking (Supplier → Warehouse → Assembly → Deployed)
- Inventory value breakdown by stage
- Low-stock alerts with per-part thresholds
- Supplier performance table
- Bulk stock update
- Optimistic UI with rollback on error
- Status report generator
- Docker Compose + GitHub Actions CI

## Planned

- Persistent database (PostgreSQL or SQLite)
- User authentication — login before editing
- Email alerts when stock drops below threshold
- Part import via CSV upload
- Dashboard charts (stock trends over time)

## Nice to Have

- Mobile-responsive layout
- Multi-warehouse support
- Supplier contact directory
