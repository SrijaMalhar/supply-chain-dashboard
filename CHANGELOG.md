# Changelog

## [1.3.0] - 2026-06-13
### Added
- Duplicate part detection with live suggestions in the add form
- Bulk stock update mode — select multiple parts and update quantities at once
- Status report generator — plain-text summary with copy to clipboard
- Optimistic UI updates — actions reflect instantly and roll back on error

## [1.2.0] - 2026-06-13
### Added
- Supplier performance table with health status per supplier
- Notes field on each part for free-text comments
- Part history log — tracks stock changes and stage advances

## [1.1.0] - 2026-06-13
### Added
- Inventory value card with breakdown by stage
- Custom reorder threshold per part
- Machine model filter and column sorting
- CSV export of the parts table
- Delete confirmation dialog

## [1.0.0] - 2026-06-13
### Added
- Initial dashboard with parts list
- Pipeline overview showing parts per stage
- Low-stock alert banner
- Add, edit, advance, and delete parts
